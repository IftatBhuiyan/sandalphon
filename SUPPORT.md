# Getting help

- **Something is corrected wrongly:** open a [wrong correction report](https://github.com/IftatBhuiyan/sandalphon/issues/new?template=wrong_correction.yml).
- **The app misbehaves:** open a [bug report](https://github.com/IftatBhuiyan/sandalphon/issues/new?template=bug_report.yml).
- **Questions and setup trouble:** ask in [Q&A](https://github.com/IftatBhuiyan/sandalphon/discussions/categories/q-a).
- **Ideas:** post in [Ideas](https://github.com/IftatBhuiyan/sandalphon/discussions/categories/ideas).
- **Security or privacy problems:** report them privately; see [SECURITY.md](SECURITY.md).

Please never paste real private text into an issue. A made-up sentence that shows the problem is best.
